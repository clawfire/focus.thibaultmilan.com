# focus.thibaultmilan.com

Landing page for **Focus Sessions**: free online body doubling sessions hosted by Thibault Milan.

- Single self-contained page: `index.html` (FR/EN toggle, Cal.com booking embed)
- Hosted on Netlify, no build step (`netlify.toml` publishes the repo root)
- Fonts: Inter + Space Mono via Bunny Fonts

To change the copy, edit the text in `index.html` and push to `main`: Netlify redeploys automatically.
